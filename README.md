# Hariharan & Indhumathi — Wedding Site

South Indian–styled wedding invitation website for **V. Hariharan** and **N. Indhumathi** (13 December 2026).

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Features

- Animated **Click to Enter** splash with temple doors
- Melam (nadaswaram & thavil) motif animations
- Couple details, muhurtham time, countdown, and invitation card image
