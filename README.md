# Hariharan & Indhumathi — Wedding Site

Modern luxury **South Indian wedding invitation** — editorial layouts, cinematic hero, minimal motion, bilingual Tamil/English.

## Run

```bash
npm install
npm run dev
```

## Personalize

Edit **`src/config/wedding.ts`**:

- `hero.imageSrc` — full-bleed couple photograph
- `couple.*.photoSrc` & `story` — portraits and bios
- `ceremony` & `events` — venue, maps URLs, schedule
- `gallery.images`, `contact.whatsappNumber`, `audio.src`

## Stack

React · Vite · TypeScript · Framer Motion
